INSTALLATION

1. Install MelonLoader (required to run the mod)

Automatic method (recommended):
Download the official MelonLoader installer from MelonWiki.
Run the installer, select the METEL game folder, and click INSTALL.

Manual method (alternative):
Download the MelonLoader archive and extract the "version.dll" and "dobby.dll" files, along with the "MelonLoader" folder, into the game installation folder.

2. Copy "MetelUnleashed.dll" into the "Mods/" folder (automatically created by MelonLoader) and launch the game.

3. Press F1 in-game to open the mod menu.

CUSTOM MUSIC

To add your own music to the game:

1. Go to the game folder
2. Go to UserData/MetelUnleashed/Music/ (The mod creates this folder automatically on first launch)
3. Place your .wav or .ogg files in this folder
4. In-game, go to CUSTOM MUSIC and refresh the list

CONVERT YOUR MP3 FILES TO .OGG OR .WAV

If your music files are in MP3 format, you can easily convert them:

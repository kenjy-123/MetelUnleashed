METEL UNLEASHED — CHANGELOG (Made by Kenjy)
   v1.0 — First Release
==========================================

🔹 NEW FEATURES
----------------------------------------------------------------------

🌊 OCEAN MODE
   - Fully transparent water with adjustable height
   - Oxygen system with air bubbles to breathe
   - Swimming & floating mechanics (Space to go up, Shift to go down)
   - Automatic water rise/fall cycle
   - Instant GameOver on drowning
   - Auto-reset in main menu

🚁 DRONE MODE
   - Flying camera
   - Controls: WASD / Space/Shift / Mouse / R to return to player
   - Optimized performance (30 FPS max, reduced resolution)

🎵 CUSTOM MUSIC
   - Load .wav / .ogg files from a dedicated folder
   - Progress bar + resume playback
   - Adjustable Pitch & Speed (sliders)
   - Mute/Unmute with M key
   - Pause button

🎮 GRAPHICS QUALITY
   - 6 levels: Legendary, Ultra, High, Medium, Low, Very Low
   - Anti-aliasing, shadows, textures, FPS limit, fog
   - Improved materials in Game
   - Sharpening effect (AMD CAS-like) for Ultra & Legendary
   - Light and realistic fog for interiors

🎨 MOD DISPLAY
   - Customizable colors (background, accent, text, buttons, borders)
   - Color presets (Green, Red, Blue, Gold, Purple, Cyan)
   - Animated particles
   - Adjustable menu size (50% → 150%)

🌍 LOCALIZATION
   - 6 languages: Français, English, Español, Deutsch, Русский, Português
   - F5 to switch languages
   - All menu texts translated

🎭 MASKS & SKINS UNLOCKER
   - Unlock all maniac masks
   - Unlock all maniac skins
   - Fisherman skin included (20 fish collected)

🔇 NOISE DISABLER
   - Disable all game noises (bells, glass, crows, dog, traps, elevator...)

📐 MENU SIZE
   - Adjustable menu size from 50% to 150%
   - F6 shortcut to cycle through sizes

⚡ VSYNC CONTROL
   - Enable/Disable VSync

📦 ITEM TELEPORT
   - View all items in the current level
   - Add items directly to inventory
   - Compatible with all Chapters

🎣 FISH COUNTER
   - Fish collection counter (0/20)
   - Unlock Fisherman skin at 20 fish
   - Gift counter (old version)
   - Pumpkin counter
